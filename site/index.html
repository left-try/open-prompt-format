A small open format for prompts

Prompts belong in your repo.

Keep prompts as readable, version-controlled files. Load the same prompt from Python or TypeScript, then connect your own provider or evaluation tooling.

Explore the repositoryQuick start

One file. Prompt and metadata.

OPF keeps the prompt body and its machine-readable metadata together in one Markdown file.

---
opf: 1
id: support.reply
version: 1.0.0
inputs:
  - name: question
    required: true
---
Answer the customer's question clearly:
{{question}}

Fits a repo-first workflow

Readable and reviewable

Use ordinary text files, Git history, and code review. No hosted registry is required.

Python and TypeScript

Load a prompt by ID, validate inputs, render variables, and inspect a stable content digest.

Provider-neutral

The format describes prompt content. Application code and adapters decide how to call a model provider.

Early and evolving

OPF is an early project proposal, not an established industry standard. The syntax and libraries are open for review and contributions.
